# ✅ Lista de Tarefas

Aplicação web desenvolvida para praticar **JavaScript, manipulação do DOM e lógica de programação**, permitindo organizar tarefas de forma simples e intuitiva.

🔗 **[Acessar projeto online](https://monteirocode1.github.io/javacript-projetos/projeto-lista-de-tarefas/)**

---

## 📸 Sobre o Projeto

O projeto consiste em uma lista de tarefas interativa, criada durante meus estudos de desenvolvimento Front-End.

O objetivo foi colocar em prática os conhecimentos de HTML, CSS e JavaScript, construindo uma aplicação que permite adicionar, acompanhar e excluir tarefas, mantendo os dados salvos no navegador.

## 🚀 Funcionalidades

- ➕ Cadastro de novas tarefas.
- ☑️ Marcação de tarefas como concluídas ou pendentes.
- 🗑️ Exclusão de tarefas.
- 💾 Armazenamento de tarefas no navegador com `localStorage`.
- 🔄 Persistência dos dados ao atualizar a página.
- 📋 Organização e acompanhamento do status das tarefas.

## 🛠️ Tecnologias Utilizadas

<p>
  <img src="https://skillicons.dev/icons?i=html,css,js" alt="HTML5, CSS3 e JavaScript" />
</p>

- **HTML5:** estruturação dos elementos da aplicação.
- **CSS3:** estilização e organização visual da interface.
- **JavaScript:** lógica de programação, manipulação do DOM e eventos.
- **LocalStorage:** armazenamento dos dados no navegador.

## 🧠 O Que Aprendi

Durante o desenvolvimento deste projeto, pratiquei conceitos importantes para minha evolução como desenvolvedor Front-End:

- Seleção e criação de elementos HTML com JavaScript.
- Manipulação do DOM e navegação entre elementos.
- Tratamento de eventos e interação com botões e checkboxes.
- Criação e organização de funções.
- Utilização de arrays e estruturas de repetição.
- Salvamento e recuperação de dados com `localStorage`.
- Atualização do estado das tarefas.
- Organização da lógica de cadastro e exclusão de itens.
